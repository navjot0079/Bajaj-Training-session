# Bajaj Training Session

A collection of Java implementations for classic Data Structures and Algorithms (DSA) problems. 

## Overview
This repository contains over 60+ standalone Java files covering various DSA concepts. All source files are located in the root directory.

### Topics Covered
Here are a few prominent problem categories included in this workspace:
- **Arrays & Strings** (`TwoSum.java`, `AnagramCheck.java`, `LongestPalindromicSubstring.java`)
- **Linked Lists** (`ReverseLinkedList.java`, `LinkedListCycle.java`, `MiddleOfLinkedList.java`)
- **Trees & Graphs** (`InvertBinaryTree.java`, `GraphBFSTraversal.java`, `NumberOfIslands.java`)
- **Dynamic Programming** (`ClimbingStairs.java`, `CoinChange.java`, `MinimumPathSum.java`)
- **Stacks & Queues** (`MinStack.java`, `ValidParentheses.java`)

## Prerequisites
- **Java Development Kit (JDK) 8+** installed on your system.

## How to Run

Compile and run any Java file directly from the root directory:

```bash
javac <ClassName>.java
java <ClassName>
```

For example:
```bash
javac TwoSum.java
java TwoSum
```
